# 用户指南

> 本文说明已安装插件的日常使用。功能是否已正式发布以 [CHANGELOG](../CHANGELOG.md) 为准。

## 权限

在 **Settings > Access Management** 分配：

| 权限 | 用途 |
| --- | --- |
| `seat-audit-monitor.view` | 查看违规记录、军团审计和令牌审查，并导出 CSV。 |
| `seat-audit-monitor.admin` | 管理监控物品与白名单、提交扫描、解析 Unknown 名称。 |

未授权用户不可见菜单，直接访问受保护页面会被拒绝。

## 配置监控物品与白名单

管理员在“审计监控 > 监控物品”中录入 EVE `type_id`。删除监控物品不会删除既有审计快照。

“白名单”分为角色与军团两类，语义不同：

- **角色白名单**：个人豁免。旧钱包/合同审计中，命中角色会被豁免；
- **军团白名单**：内部合同豁免。仅在旧合同双方军团均命中时豁免；
- 军团审计 2.0 仅对外部方应用白名单，不能直接套用旧违规记录的筛选口径。

白名单更新会影响后续扫描；旧违规记录页面也会按其专用规则实时过滤历史显示。

## 违规记录

“违规记录”展示旧 1.0 的市场交易与监控物品合同审计结果。页面支持审计类型、日期和关键词筛选，并可导出当前筛选范围的 CSV。合同可查看审计快照详情；CSV 使用流式输出并防护 Excel/WPS 公式注入。

## 军团审计

“军团审计”展示固定受审军团的 ISK Donation 与成员低价合同结果。管理员可按当前标签提交异步扫描，查看者可按页面筛选导出 CSV。

- 日期和关键词只过滤已入库结果，不能改变 `audit_from` 或 cursor；
- Donation 没有物品级明细或合同详情；
- 扫描需先由运维完成军团启用、队列和共享 Cache 配置；
- 页面提交后请等待任务结果，不要用重复点击替代任务去重。

### 2.2.0 交易视图与名称解析

`2.2.0` 提供军团审计九列交易视图、成员合同物品摘要、合同详情弹窗、关键词筛选，以及军团页的 Unknown 名称解析。页面按 `direction` 显式展示发起方和接收方，军团名称使用审计时的快照，不以当前 affiliation 覆盖历史事实。

## 解析 Unknown 名称

当页面显示 `Unknown (ID: …)` 时，管理员可使用“解析未知来源”。任务会异步补全角色、军团或联盟的本地显示名称；仅已确认角色会补全当前 affiliation。

该操作会调用公开 ESI 并写入本地缓存，但不会读取 token，也不会把当前 affiliation 改写为历史审计快照。它不解析星系、空间站、建筑或合同物理位置。

## 令牌审查

“令牌审查”是只读页面，用于查看当前成员的本地 SeAT 令牌状态投影。它不会刷新 token、调用 ESI/SSO 或判断实时授权有效性。令牌状态、时间来源、导出字段和禁止读取的数据见[令牌审查安全契约](token-audit-security.md)。

## 命令行入口

管理员可在授权维护窗口运行：

```bash
php artisan seat:audit:scan --type=wallet
php artisan seat:audit:scan --type=contracts
php artisan seat:audit:scan --type=donations
php artisan seat:audit:scan --type=member-contracts
```

完整运行限制、`--since` 语义、队列要求和验收步骤见[运行手册](operations.md)。
